# Data

Files committed here are public and redistributable (see `../THIRD_PARTY_NOTICES.md`). To run the full pipeline, download
the files below into `data/raw/` with exactly these names. The paper's evaluation (`evaluation/`) does not need them.

| Save as `data/raw/...` | Where to get it |
|---|---|
| `AIOE_DataAppendix.xlsx` | https://github.com/AIOE-Data/AIOE (file of the same name). Cite Felten, Raj & Seamans (2021). |
| `Language Modeling AIOE and AIIE.xlsx` | https://github.com/AIOE-Data/AIOE (file of the same name). Cite Felten, Raj & Seamans (2023). |
| `postings.csv.zip` | Kaggle, "LinkedIn Job Postings (2023–2024)" by arshkon: https://www.kaggle.com/datasets/arshkon/linkedin-job-postings. Download `postings.csv` and compress it to `postings.csv.zip`. |
| `jobstreet_all_job_dataset.csv` | Kaggle, "Jobstreet Job Postings" by azraimohamad: https://www.kaggle.com/datasets/azraimohamad/jobstreet-all-job-dataset. The dataset is updated over time; the reported run used the version available in August 2026. |
| `Coursera.csv` | Kaggle, "Coursera Courses Dataset 2021": https://www.kaggle.com/datasets/khusheekapoor/coursera-courses-dataset-2021 |
| `elatih_courses.csv` | Course listings compiled by the authors from the HRD Corp e-LATiH platform (https://elatih.hrdcorp.gov.my). Not redistributed; contact the authors. |

Committed here: O\*NET 30.3 files (`onet/`), BLS OEWS national files May 2015 to May 2024 (`US National Wages/`), BLS SOC
2010–2018 and ISCO-08–SOC 2010 crosswalks, the DOSM Salaries & Wages Survey 2024 workbook, the GPT exposure file
`occ_level.csv` (Eloundou et al., 2024), and in `../data/third_party/` the Microsoft Working with AI applicability scores.
